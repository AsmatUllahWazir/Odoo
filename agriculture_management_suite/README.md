# Agriculture & Farm Management Suite for Odoo

## Overview
A comprehensive, production-ready Odoo module for commercial agriculture operations.
Manage fields, crops, seasons, input applications, harvests, equipment, and traceability
—all integrated with Inventory, Purchase, Accounting, and Maintenance.

## Features
- **Field & Parcel Management** with GIS coordinates and soil data
- **Crop & Season Planning** with budget vs. actual tracking
- **Input Applications** (fertilizer, pesticide, irrigation) with lot traceability
- **Harvest Management** with quality grading and stock integration
- **Weather Logging** with API integration hooks
- **Disease & Pest Tracking** with treatment history
- **Equipment Management** linked to Odoo Maintenance
- **Seasonal P&L** automatic profit/loss reporting
- **Multi-Company Support**

## Installation
1. Copy `agriculture_management` to your Odoo addons directory
2. Update app list
3. Install "Agriculture & Farm Management Suite"
4. Assign users to "Farm User" or "Farm Manager" groups
5. Configure Weather API in Settings -> Agriculture

## Dependencies
- base, mail, stock, purchase, account, maintenance, web, portal

## Compatibility
- Odoo 17.0 / 18.0 Community & Enterprise
