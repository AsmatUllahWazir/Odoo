Detailed Operational Workflows & System Architecture

🌱 Crop Cycle Workflow

  • Field Selection: Choose field with soil and location data.
  • Crop Selection: Select crop variety and growing period.
  • Season Planning: Set budget, expected yield, and targets.
  • Planting: Record planting date, seed lot, and density.
  • Growth Monitoring: Track stages from vegetative to maturity.
  • Input Applications: Log fertilizer, pesticide, irrigation.
  • Disease/Pest: Detect, treat, and analyze outbreaks.
  • Harvest: Record quality, moisture, and yield.
  • P&L Analysis: Automatic profit/loss calculation.

📦 Traceability Workflow

  • Input Tracking: Each input lot linked to purchase order.
  • Application Log: Input applied to specific field with date and weather.
  • Cultivation Record: All activities logged on the field.
  • Harvest Batch: Unique traceability code generated.
  • Stock Reception: Harvest linked to inventory lot.
  • Sales Order: Product sold with traceability code.
  • Customer Portal: Scan code to see full journey.

🛡️ Disease & Pest Management

  • Detection: Regular field scouting and reporting.
  • Incident Log: Record disease/pest type and severity.
  • Treatment: Apply treatment with product and dosage.
  • Effectiveness: Track treatment success rate.
  • Financial Impact: Calculate yield loss and cost.
  • Trend Analysis: Identify patterns by field and crop.

💰 Seasonal P&L Workflow

  • Budget Setup: Define planned costs per category.
  • Cost Tracking: Input applications create journal entries.
  • Revenue Recording: Harvests linked to sales orders.
  • Equipment Depreciation: Auto-calculated per season.

  • PDF Report: Professional report generation.

Enterprise Backend Configuration & Access Rights

Granular Security Groups Matrix

The module defines 3 distinct security access groups inside Odoo 17 & 18 User Settings. Each role strictly controls what the logged-in user can view, create, edit, or export:

Security Role Intended Staff Role Permissions & Capabilities
Farm User Field Workers / Operators Log inputs, harvests, view assigned fields.
Farm Manager Agronomists / Farm Managers Create seasons, manage crops, view dashboard, approve inputs.
Farm Administrator Farm Owners / Directors Complete administrative control, configure settings, manage users, full P&L access.

System Configuration Parameters

  • Weather API Key: Configure OpenWeatherMap or WeatherAPI keys.
  • Traceability Prefix: Set prefix for harvest traceability codes.
  • Pre-Harvest Interval: Default PHI tracking days.
  • Auto Stock Moves: Enable/disable auto-inventory creation.
  • Equipment Depreciation: Set default depreciation rate.
  • Season Status Workflow: Customize season lifecycle states.

Key Data Models

  • farm.season: Season planning with budget and P&L.
  • farm.cultivation: Crop cultivation with growth stages.
  • farm.input.application: Input logging with PHI tracking.
  • farm.harvest: Harvest recording with quality and traceability.
  • farm.disease.incident: Disease and pest tracking.
  • farm.equipment: Farm machinery with depreciation.
  • farm.weather: Daily weather data integration.

Native Odoo Integrations & External APIs

📦 Odoo Native Integrations

  • Inventory (stock): Auto-create stock moves for inputs consumed and harvests received.
  • Purchase (purchase): Link input applications to purchase orders and vendor invoices.
  • Accounting (account): Season-linked invoices and bills. Automatic P&L per crop.
  • Maintenance (maintenance): Farm equipment linked to maintenance requests.
  • Portal (portal): Public traceability page for customers.
  • Discuss (mail): Chatter on every record for team collaboration.

📡 External Integrations

  • OpenWeatherMap: Fetch real-time and forecast weather data.
  • WeatherAPI: Alternative weather data provider.
  • GIS Integration: GeoJSON polygon support for field mapping.
  • Export/Import: CSV/Excel import/export for all models.
  • PDF Generation: QWeb PDF reports for seasons and harvests.

API Endpoints (REST)

  • GET /api/farm/fields: Retrieve all fields with GIS data.
  • GET /api/farm/seasons: Get active and historical seasons.
  • GET /api/farm/harvests: List harvests with traceability codes.
  • POST /api/farm/input-application: Log new input application.
  • GET /api/farm/pnl/{season_id}: Get profit/loss for a season.

❓ Frequently Asked Questions

What versions of Odoo does this module support?

Odoo 17.0 and 18.0, both Community and Enterprise editions.

Does it work with multi-company setups?

Yes, the module is fully multi-company compatible. Each farm/operation can be managed as a separate company with independent data.

Yes, the module supports OpenWeatherMap and WeatherAPI for automatic weather data fetching.
