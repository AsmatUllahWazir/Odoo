🔄 Complete Hotel Operational Workflows

End-to-end workflows covering the entire guest journey from booking to check-out

📋 Reservation to Check-out Workflow

  1. Reservation Creation: Guest searches rooms → Selects dates → Chooses room type → Creates reservation (Draft).
  2. Confirmation: Confirm reservation → Room status becomes Reserved → Send confirmation email.
  3. Check-in: Guest arrives → Click Check-in → Room status becomes Occupied → Folio auto-created.
  4. During Stay: Add extra services (breakfast, laundry, spa) → Services added to folio.
  5. Check-out: Guest departs → Click Check-out → Room status becomes Dirty → Folio settled.
  6. Housekeeping: Room cleaned → Status becomes Available → Ready for next booking.

🧹 Housekeeping & Maintenance Workflow

  1. Status Detection: Room becomes Dirty after check-out or manual update.
  2. Task Creation: Housekeeping task created with priority and assignment.
  3. Task Assignment: Staff assigned → Task status becomes Assigned.
  4. Cleaning: Staff starts cleaning → Status becomes In Progress.
  5. Completion: Cleaning completed → Status becomes Completed → Room becomes Clean/Available.
  6. Inspection: Supervisor inspects → Status becomes Inspected → Quality rating recorded.

💰 Folio & Payment Workflow

  1. Folio Creation: Auto-created on check-in with room charges.
  2. Service Addition: Extra services added during stay (breakfast, spa, etc.).
  3. Balance Tracking: Real-time balance due with payment status.
  4. Payment Registration: Multiple payment methods (cash, card, online).
  5. Folio Settlement: Settle folio at check-out → Generate invoice.
  6. Receipt Generation: Auto-send payment receipt via email.

👤 Guest Journey & Loyalty Workflow

  1. Guest Registration: New guest created with all demographics and preferences.
  2. Stay Recording: Each stay tracked with dates, nights, and spending.
  3. History Building: Complete stay history with preferred room types.
  4. Loyalty Points: Points accumulated based on stays and spending.
  5. VIP Status: Automatic or manual VIP status based on history.
  6. Personalization: Personalized service based on guest preferences.

Detailed Operational Workflows & System Architecture

📋 Reservation Workflow

  1. Reservation Creation: Guest or receptionist creates reservation with dates and room selection.
  2. Conflict Check: System automatically checks for double booking conflicts.
  3. Confirmation: Reservation confirmed → Room status becomes Reserved.
  4. Pre-arrival: Send confirmation email with booking details.
  5. Check-in: Guest arrives → Room status becomes Occupied → Folio created.
  6. During Stay: Add services, manage guest requests, track expenses.
  7. Check-out: Guest departs → Room status becomes Dirty → Folio settled.
  8. Post Check-out: Send folio email → Room cleaned → Available for next booking.

🧹 Housekeeping Workflow

  1. Room Status Change: Room becomes Dirty after check-out.
  2. Task Creation: Housekeeping task auto-created or manually assigned.
  3. Priority Assignment: Set priority (Urgent/High/Normal/Low).
  4. Staff Assignment: Assign to available housekeeping staff.
  5. Task Start: Staff starts cleaning → Status becomes In Progress.
  6. Completion: Staff completes cleaning → Status becomes Completed.
  7. Inspection: Supervisor inspects → Quality rating recorded.
  8. Room Available: Room status becomes Available for next booking.

💰 Financial & Billing Workflow

  1. Folio Creation: Auto-created on check-in with room charges.
  2. Service Addition: Staff adds services (breakfast, laundry, spa).
  3. Real-time Calculation: Total amount updates with each service added.
  4. Payment Registration: Multiple payment methods accepted.
  5. Balance Tracking: Real-time balance due monitoring.
  6. Folio Settlement: Settle at check-out → Generate invoice.
  7. Receipt Generation: Auto-send receipt to guest email.
  8. Accounting Integration: Seamless Odoo Accounting sync.

👤 Guest Lifecycle Workflow

  1. Guest Creation: New guest registered with complete demographics.
  2. ID Verification: Document verification and storage.
  3. Preference Capture: Room preferences, dietary needs, accessibility.
  4. First Stay: First booking and stay experience.
  5. History Building: All stays, nights, and spending tracked.

Security Groups & Access Rights Matrix

🔐 Granular Security Groups

The module defines 4 distinct security access groups inside Odoo 17 User Settings. Each role strictly controls what the logged-in user can view, create, edit, or delete:

Security Role Intended Staff Permissions & Capabilities
Receptionist Front Desk Staff Create reservations, check-in/out guests, manage folios, add services, view guest profiles.
Housekeeping Cleaning Staff View room status, manage cleaning tasks, update room status, track supplies.
Manager Hotel Managers Full access to all features: reservations, rooms, guests, folios, housekeeping, services, payments, channels, configuration, reports.
Owner Hotel Owners / Administrators Complete administrative control including user management, system settings, and all data.

🔒 Model-Level Access Control

Access control is implemented at the model level using Odoo's security framework:

  • Read Access: All groups have read access to relevant models.
  • Create Access: Receptionist, Manager, Owner can create reservations and guests.
  • Write Access: Limited to authorized roles for sensitive operations.
  • Delete Access: Restricted to Manager and Owner only.
  • Record Rules: Additional record-level security for multi-property setups.
