🔄 Complete Hotel Operational Workflows

End-to-end workflows covering the entire guest journey from booking to check-out

📋 Reservation to Check-out Workflow

  1. Guest Search: Guest searches for available rooms with date selection.
  2. Room Selection: Choose room type and select specific room(s).
  3. Reservation Creation: Create reservation with guest details (Draft state).
  4. Conflict Check: System automatically checks for double booking conflicts.
  5. Confirmation: Confirm reservation → Room status becomes Reserved.
  6. Pre-arrival: Send confirmation email with booking details.
  7. Check-in Process: Guest arrives → Click Check-in → Room status becomes Occupied.
  8. Folio Creation: Folio auto-created with room charges.
  9. During Stay: Add extra services, manage guest requests, track expenses.
  10. Check-out Process: Guest departs → Click Check-out → Room status becomes Dirty.
  11. Folio Settlement: Settle folio with payment → Generate invoice.
  12. Post Check-out: Send folio email → Room cleaned → Available for next booking.

🧹 Housekeeping & Maintenance Workflow

  1. Status Detection: Room becomes Dirty after check-out or manual update.
  2. Task Creation: Housekeeping task auto-created or manually assigned.
  3. Priority Assignment: Set priority (Urgent/High/Normal/Low) based on requirements.
  4. Staff Assignment: Assign to available housekeeping staff member.
  5. Task Start: Staff starts cleaning → Status becomes In Progress.
  6. Cleaning Process: Staff completes cleaning tasks and checklist items.
  7. Task Completion: Staff completes cleaning → Status becomes Completed.
  8. Quality Inspection: Supervisor inspects room → Quality rating recorded.
  9. Redo if Needed: If quality insufficient, task is reopened for redo.
  10. Room Release: Room status becomes Available for next booking.

💰 Financial & Billing Workflow

  1. Folio Creation: Auto-created on check-in with room charges calculated.
  2. Service Addition: Staff adds extra services to folio during stay.
  3. Real-time Calculation: Total amount updates with each service added.
  4. Tax & Discount: Apply tax percentage, service charge, and discounts.
  5. Payment Registration: Multiple payment methods accepted (cash, card, online).
  6. Balance Tracking: Real-time balance due monitoring and alerts.
  7. Folio Settlement: Settle at check-out → Generate invoice PDF.
  8. Receipt Generation: Auto-send payment receipt to guest email.
  9. Accounting Integration: Seamless Odoo Accounting sync for financial reporting.
  10. Audit Trail: Complete transaction history and audit trail.

👤 Guest Lifecycle & Loyalty Workflow

  1. Guest Registration: New guest created with complete demographics and preferences.
  2. ID Verification: Document verification and secure storage.
  3. Preference Capture: Room preferences, dietary needs, accessibility requirements.
  4. First Stay: First booking and stay experience with history tracking.
  5. History Building: All stays, nights, and spending automatically tracked.
  6. Loyalty Accumulation: Points earned based on stays and spending patterns.
  7. VIP Status: Automatic VIP upgrade based on stay history and points.
  8. Personalized Service: Tailored experience based on guest preferences.
  9. Blacklist Management: Track and manage blacklisted guests.
  10. Guest Analytics: Analyze guest behavior and spending patterns.

🔐 Security Groups & Access Rights Matrix

🔐 Granular Security Groups

The module defines 4 distinct security access groups inside Odoo 17 User Settings. Each role strictly controls what the logged-in user can view, create, edit, or delete:

Security Role Intended Staff Permissions & Capabilities
Receptionist Front Desk Staff Create reservations, check-in/out guests, manage folios, add services, view guest profiles, view room status.
Housekeeping Cleaning Staff View room status, manage cleaning tasks, update room status, track supplies, view housekeeping tasks.
Manager Hotel Managers Full access to all features: reservations, rooms, guests, folios, housekeeping, services, payments, channels, configuration, reports.
Owner Hotel Owners / Administrators Complete administrative control including user management, system settings, and all data.

🔒 Model-Level Access Control

Access control is implemented at the model level using Odoo's security framework:

Read Access All groups have read access to relevant models based on their role.
Create Access Receptionist, Manager, Owner can create reservations and guests.
Write Access Limited to authorized roles for sensitive operations.
Delete Access Restricted to Manager and Owner only for data integrity.
Additional Security Features:
  • Record-level security for multi-property setups
  • Audit trail with Chatter and activity tracking
  • Activity planning and notifications
  • Field-level security for sensitive data
