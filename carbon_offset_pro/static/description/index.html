🔧 Installation

  1. Purchase and download the module from Odoo App Store
  2. Install as standard Odoo module (Apps > Update Apps List)
  3. Go to Carbon Offset > Configuration to set default values
  4. Add emission factors to your products
  5. Create offset projects or use demo data
  6. Start tracking carbon footprint on sales orders!
