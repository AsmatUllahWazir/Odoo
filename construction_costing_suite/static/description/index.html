How the Module Works

Core Concept

The Big Picture

The Construction Management Suite operates as a centralized project management engine that connects all aspects of construction projects into a single, cohesive system. It works by:

1. Data Centralization

All project data - budgets, costs, materials, subcontractors, milestones - is stored in interconnected Odoo models. This creates a single source of truth that eliminates data silos and ensures consistency across the organization.

2. Automated Workflows

The module implements state-machine based workflows that automate approval processes, requisition creation, invoice generation, and cost tracking. Each state transition triggers specific actions and notifications.

3. Real-time Calculations

Computational fields automatically calculate totals, variances, completions, and profitability in real-time. Using Odoo's @api.depends decorators, values update instantly when underlying data changes.

4. System Integration

The module seamlessly integrates with Odoo's core modules: Project (tasks), Account (invoices), Purchase (orders), Stock (inventory), and HR Timesheets. This creates a complete ecosystem for construction management.

Core Business Logic

BOQ → Job Cost Generation

When a BOQ is approved, the system automatically creates job cost lines for each BOQ line. This establishes the budget baseline against which actual costs will be tracked.

Cost Tracking & Variance Analysis

The system aggregates actual costs from purchase orders, timesheets, and stock moves. It then compares them against budgeted amounts to calculate cost variances in real-time.

Milestone-based Billing

Milestones represent billable project checkpoints. When a milestone is marked complete, the system automatically calculates retainage, generates the net amount, and can create a customer invoice.

Subcontractor Management

Subcontractor tasks track contract values, progress, and invoices. The system calculates remaining amounts and prevents over-invoicing by tracking total invoiced amounts.

# Example: BOQ Total Calculation
@api.depends('line_ids', 'line_ids.subtotal')
def _compute_totals(self):
    for boq in self:
        boq.total = sum(boq.line_ids.mapped('subtotal'))

# Example: Cost Variance Calculation
@api.depends('budgeted_amount', 'actual_cost')
def _compute_variances(self):
    for line in self:
        line.cost_variance = line.budgeted_amount - line.actual_cost

# Example: Milestone Retainage Calculation
@api.depends('amount', 'retainage_percentage')
def _compute_retainage(self):
    for milestone in self:
        milestone.retainage_amount = milestone.amount * (milestone.retainage_percentage / 100)
        milestone.net_amount = milestone.amount - milestone.retainage_amount

Workflow & State Management

Step by Step

Complete Project Lifecycle

Step 1: Project Setup

Create Construction Project

User creates a project with is_construction_project=True. This enables all construction-specific fields and features.

Key Actions: Set project type, construction status, site address, and contract value
Step 2: BOQ Creation

Create Bill of Quantities

Create BOQ with line items for materials, labor, subcontractors, and equipment. Each line includes product, quantity, and unit price.

Key Actions: Add products, set quantities, upload from Excel, version control
Step 3: BOQ Approval

Submit for Approval

BOQ moves through states: draft → under_review → approved. On approval, the system auto-creates job cost lines and material requisitions.

Auto-Generated: Job cost lines (budget tracking) and Material requisitions (if flagged)
Step 4: Task Management

Create Construction Tasks

Create tasks with construction-specific fields: task type, estimated cost, dependencies, and crew assignments.

Key Features: Task dependencies, progress tracking, cost variance analysis
Step 5: Material Requisitions

Request & Approve Materials

Create requisitions from tasks or BOQ. States: draft → submitted → approved → partially_delivered → delivered.

Integration: Creates purchase orders and stock pickings automatically
Step 6: Subcontractor Tasks

Assign & Track Subcontractors

Assign tasks to subcontractors. States: pending → assigned → in_progress → under_review → completed.

Key Features: Progress tracking, quality ratings, auto-invoicing on completion
Step 7: Progress Billing

Generate Progress Invoices

Create invoices based on milestones or percentage completion. The system calculates retainage and net amounts automatically.

Billing Methods: Milestone-based, Percentage completion, Fixed amount, Time & Materials
Step 8: Project Closure

Close & Analyze Project

Generate final reports with profit/loss analysis, cost breakdown, and performance metrics.

Output: Final cost analysis, profit margin, audit trail, and closing reports

Key Methods & Business Logic

# BOQ Approval - Creates Job Cost Lines
def _create_job_cost_lines(self):
    JobCostLine = self.env['construction.job.cost.line']
    for boq in self:
        for line in boq.line_ids:
            existing = JobCostLine.search([
                ('project_id', '=', boq.project_id.id),
                ('product_id', '=', line.product_id.id)
            ])
            if not existing:
                JobCostLine.create({
                    'project_id': boq.project_id.id,
                    'product_id': line.product_id.id,
                    'budgeted_amount': line.subtotal,
                })

# Milestone Invoice Generation
def action_generate_invoice(self):
    for milestone in self:
        invoice_vals = {
            'move_type': 'out_invoice',
            'partner_id': milestone.project_id.partner_id.id,
            'invoice_line_ids': [(0, 0, {
                'name': f"Milestone: {milestone.name}",
                'price_unit': milestone.net_amount
            })]
        }
        invoice = self.env['account.move'].create(invoice_vals)
        milestone.invoice_id = invoice.id
        milestone.state = 'invoiced'

# Subcontractor Task Completion
def action_complete(self):
    for task in self:
        task.status = 'completed'
        task.completion_date = fields.Date.today()
        task.progress_percentage = 100.0
        # Auto-generate invoice if configured
        if task.contract_value > 0:
            task.action_generate_invoice()
