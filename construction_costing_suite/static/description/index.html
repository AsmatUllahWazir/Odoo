How the Module Works

Core Engine

The Construction Management Suite acts as a centralized project management engine that interconnects all construction workflows — from budgeting to billing — within a single Odoo environment. It replaces fragmented spreadsheets and manual processes with a unified, automated system.

1. Data Centralization

All project data — budgets, actual costs, materials, subcontractors, milestones — lives in interconnected Odoo models. This eliminates data silos and ensures a single source of truth for your entire organization.

  • No more duplicate data entry
  • Consistent reporting across projects
  • Real-time data access for all stakeholders
  • Centralized document management

2. Automated Workflows

State‑machine driven workflows automate approvals, requisition creation, invoice generation, and cost tracking. Each state transition triggers notifications and next‑step actions automatically.

  • BOQ approval → auto-create cost lines
  • Requisition approval → auto-create PO
  • Milestone completion → auto-create invoice
  • Subcontractor completion → auto-create vendor invoice

3. Real‑time Calculations

Computed fields powered by @api.depends recalculate totals, variances, completion percentages, and profitability instantly as underlying data changes — no manual recalculations needed.

  • Budget vs Actual variance analysis
  • Physical & financial completion %
  • Retainage & net amount calculation
  • Cost variance alerts

4. Seamless Integration

Deep integration with Odoo's core apps: Project (tasks), Accounting (invoices), Purchase (orders), Inventory (stock), and Timesheets — creating a complete construction ecosystem.

  • Project → Task → Cost tracking
  • Requisition → PO → Stock picking
  • Milestone → Invoice → Payment
  • Timesheet → Labor costing

Computed Fields & Business Logic

# BOQ Total Calculation
@api.depends('line_ids', 'line_ids.subtotal')
def _compute_totals(self):
    for boq in self:
        boq.total = sum(boq.line_ids.mapped('subtotal'))

# Cost Variance Calculation
@api.depends('budgeted_amount', 'actual_cost')
def _compute_variances(self):
    for line in self:
        line.cost_variance = line.budgeted_amount - line.actual_cost

# Milestone Retainage Calculation
@api.depends('amount', 'retainage_percentage')
def _compute_retainage(self):
    for milestone in self:
        milestone.retainage_amount = milestone.amount * (milestone.retainage_percentage / 100)
        milestone.net_amount = milestone.amount - milestone.retainage_amount

# Project Physical Completion
@api.depends('task_ids', 'task_ids.stage_id')
def _compute_completion(self):
    for project in self:
        done_tasks = project.task_ids.filtered(lambda t: t.stage_id.fold)
        project.physical_completion = (len(done_tasks) / len(project.task_ids)) * 100 if project.task_ids else 0.0

# Subcontractor Remaining Amount
@api.depends('invoice_ids', 'invoice_ids.amount_total')
def _compute_invoiced_amount(self):
    for task in self:
        total_invoiced = sum(task.invoice_ids.filtered(lambda i: i.state == 'posted').mapped('amount_total'))
        task.invoiced_amount = total_invoiced
        task.remaining_amount = task.contract_value - total_invoiced

Workflow & State Management

Step by Step
Step 1

Project Setup

Create a project with is_construction_project=True to enable all construction‑specific fields and features. Set project type, construction status, site address, and contract value.

Key Actions: Project type, status, site details, contract value
Step 2

BOQ Creation

Build your Bill of Quantities with line items for materials, labor, subcontractors, and equipment. Import from Excel if needed. Each line includes product, quantity, and unit price.

Key Actions: Add products, quantities, unit prices, version control, Excel import
Step 3

BOQ Approval

BOQ moves through draft → under_review → approved (or rejected/cancelled). On approval, the system auto‑creates job cost lines and material requisitions.

Auto‑generates: Job cost lines (budget) & Requisitions (if flagged)
Step 4

Task Management

Create construction tasks with type, estimated cost, dependencies, and crew assignments. Track physical and financial progress with real-time variance analysis.

Key Features: Dependencies, progress tracking, cost variance, crew assignments
Step 5

Material Requisitions

Create requisitions from tasks or BOQ. States: draft → submitted → approved → partially_delivered → delivered. Auto‑creates purchase orders and stock pickings.

Integration: Auto‑creates Purchase Orders & Stock Pickings
Step 6

Subcontractor Tasks

Assign tasks to subcontractors. States: pending → assigned → in_progress → under_review → completed. Includes progress tracking and quality ratings.

Key Features: Progress tracking, quality rating, auto‑invoicing on completion
Step 7

Progress Billing

Generate invoices based on milestones, percentage completion, or fixed amount. Retainage is calculated automatically. Supports multiple billing methods.

Methods: Milestone‑based, % completion, Fixed amount, Time & Materials
Step 8

Project Closure

Generate final reports with profit/loss analysis, cost breakdown, and audit trail. Archive the project when done.

Output: Final cost, profit margin, audit trail, closing report

# BOQ Approval – Creates Job Cost Lines
def _create_job_cost_lines(self):
    JobCostLine = self.env['construction.job.cost.line']
    for boq in self:
        for line in boq.line_ids:
            existing = JobCostLine.search([
                ('project_id', '=', boq.project_id.id),
                ('product_id', '=', line.product_id.id)
            ])
            if not existing:
                JobCostLine.create({
                    'project_id': boq.project_id.id,
                    'product_id': line.product_id.id,
                    'budgeted_amount': line.subtotal,
                })

# Milestone Invoice Generation
def action_generate_invoice(self):
    for milestone in self:
        invoice_vals = {
            'move_type': 'out_invoice',
            'partner_id': milestone.project_id.partner_id.id,
            'invoice_line_ids': [(0, 0, {
                'name': f"Milestone: {milestone.name}",
                'price_unit': milestone.net_amount
            })]
        }
        invoice = self.env['account.move'].create(invoice_vals)
        milestone.invoice_id = invoice.id
        milestone.state = 'invoiced'

# Subcontractor Task Completion
def action_complete(self):
    for task in self:
        task.status = 'completed'
        task.completion_date = fields.Date.today()
        task.progress_percentage = 100.0
        if task.contract_value > 0:
            task.action_generate_invoice()
