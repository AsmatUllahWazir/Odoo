Detailed Operational Workflows & System Architecture

📋 Daily Log Workflow

  • Draft: Site supervisor creates new log.
  • Fill Details: Add weather, manpower, materials, progress.
  • Add Safety: Record observations, incidents, toolbox talks.
  • Attach Photos: Upload site photos and evidence.
  • Submit: Submit for project manager approval.
  • Approve: Project manager reviews and approves.
  • Lock: Log becomes read-only after approval.
  • PDF Report: Automatic PDF generation on approval.

⚠️ Safety Observation Workflow

  • Report: Worker reports safety observation.
  • Severity: Assign severity level (Low, Medium, High, Critical).
  • Assign: Assign to responsible person.
  • In Progress: Responsible person works on corrective action.
  • Close: Observation closed with corrective action completed.
  • Escalate: Auto-escalate if overdue.
  • Task: Create follow-up task from observation.

🚨 Incident Report Workflow

  • Report: Incident reported with type and severity.
  • Investigation: Investigation lead assigned.
  • Findings: Root cause and investigation findings recorded.
  • Actions: Immediate and preventive actions defined.
  • Resolve: Incident resolved with actions completed.
  • Close: Incident report closed.
  • Task: Create follow-up task for preventive actions.

✅ Safety Checklist Workflow

  • Template: Create reusable checklist templates.
  • Execute: Start checklist execution on site.
  • Respond: Complete checklist items with responses.
  • Complete: Mark checklist as completed.
  • Result: Pass, Fail, or Partial Pass with pass rate.
  • Report: Generate checklist report.

Enterprise Backend Configuration & Access Rights

Granular Security Groups Matrix

The module defines 3 distinct security access groups inside Odoo 17 User Settings. Each role strictly controls what the logged-in user can view, create, edit, or export:

Site Worker Field Staff Create and edit own logs, report safety observations, view assigned tasks.
Site Supervisor Supervisory Staff Manage logs, approve/reject observations, manage toolbox talks, view all data.
Project Manager Management Complete administrative control over all logs, safety data, reporting, and user management.

  • Auto-Inventory: Enable/disable automatic inventory moves.
  • Default Supervisor: Set default site supervisor.
  • Log Sequence: Configurable number sequence for logs.
