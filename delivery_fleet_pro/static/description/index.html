Configuration and extensibility

The module extends standard Odoo responsibilities instead of replacing them.

Core integrations

Standard Odoo stock.picking, sale.order, fleet.vehicle, hr.employee, res.partner, mail and account records remain the source systems for their respective domains.

Routing providers

The routing service provides a heuristic engine plus integration hooks for OpenRouteService and Google-style routing responses. Provider-specific credentials and policy can be configured without changing the operational data model.

Production note: Before marketplace publication, run the module against the exact target Odoo 17 build and PostgreSQL environment, install it on a clean database, upgrade it on a database containing existing delivery data, and execute the included test suite. Static validation is valuable but cannot replace a live Odoo registry/database test.

Recommended deployment model

  1. Install and configure company-level delivery defaults.
  2. Define delivery services, SLAs, zones, failure reasons and pricing rules.
  3. Complete driver schedules, licenses and fleet capacity information.
  4. Connect warehouse pickings to delivery routes through the planning workflow.
  5. Use the Command Center as the dispatch team's daily cockpit.
  6. Require POD controls according to commercial/service policy.
  7. Review exception aging daily and route profitability weekly.
  8. Use driver scorecards and vehicle utilization reports for continuous improvement.
