Features

Everything you need to stay compliant

Built as a generic, reusable engine — not tied to HR, Fleet, or any single app.

Attach to any record

Link a tracked document to a Contact, Employee, Vehicle, Equipment, Project, or any custom model — with a one-click "Open Related Record" button.

Configurable document types

Passport, Driving License, Insurance, Contract, Certification, Warranty, Work Permit — or add your own, each with default warning windows.

Multi-stage reminders

Set a reminder schedule like 30 / 15 / 7 / 1 days before expiry. Each threshold fires a chatter notification and an activity — automatically.

Guided renewal wizard

Renew in one click: set the new expiry date, add a note, and the full renewal history stays logged in the document's chatter.

Compliance dashboard

Color-coded list, Kanban grouped by status, Calendar, and Pivot/Graph views to see what's Valid, Expiring, or Expired at a glance.

Granular security

Dedicated User / Manager access groups with multi-company record rules, so teams only see what they should.

How it works

Popular use cases

  • HR compliance — passports, visas, work permits, professional certifications per employee.
  • Fleet management — vehicle insurance, registration, and inspection due dates.
  • Vendor & contract management — supplier agreements, SLAs, and lease renewals.

  • Insurance tracking — general liability, property, and professional indemnity policies.

Security & access

  • User group — create, view and update tracked documents.
  • Manager group — full access, incl. document type configuration & deletion.
  • Multi-company record rules included out of the box.
  • Full chatter, followers & activity log on every document.
  • Global defaults configurable under Settings > General Settings.
