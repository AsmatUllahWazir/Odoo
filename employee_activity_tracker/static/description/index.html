📋 Overview

Employee Activity Tracker & Monitor is a complete, advanced activity tracking and monitoring system for Odoo. It gives you unparalleled visibility into every action taken by your users—from login to logout. Whether you are a CEO, HR Manager, Security Officer, or System Administrator, this module helps you maintain security, improve productivity, and ensure compliance.

The module automatically tracks all CRUD operations, field-level changes (old vs. new values), button clicks, menu/URL access, and session details (IP, browser, OS, device type) with zero configuration required. A beautiful real-time dashboard provides instant insights into who is online, what they are doing, and any suspicious activity.
