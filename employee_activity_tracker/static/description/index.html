Detailed Operational Workflows & System Architecture

🕒 Session Lifecycle Workflow

  • Login Event: User logs in → Session record created with IP, user agent.
  • Activity Tracking: All user actions (CRUD, button clicks) logged during session.
  • Idle Detection: After configured idle threshold, status changes to Idle.
  • Logout Event: User logs out → Session ends with total duration.
  • Force Logout: Admin can terminate any active session.

📝 Activity Logging Workflow

  • User Action: User performs any operation (create/write/delete).
  • ORM Hook: System intercepts the operation and captures context.
  • Field Tracking: If write, captures old and new values for each field.
  • Log Creation: Activity log entry created with all details.
  • Async Insertion: Logs are inserted asynchronously for performance.

🛡️ Security Alert Workflow

  • Monitoring: System continuously monitors for suspicious events.
  • Detection: Failed logins, brute-force attempts, developer mode toggles.
  • Alert Creation: Security alert record created with severity level.
  • Notification: Admin notified via email or in-app notification.
  • Dashboard Display: Alerts displayed on CEO dashboard.

📬 Email Reporting Workflow

  • Schedule: Cron jobs run daily and weekly (Monday).
  • Data Collection: Gather activity stats, session data, alerts.
  • Report Generation: Create rich HTML email with charts and summaries.
  • Delivery: Email sent to configured recipients.
  • Logging: Report delivery logged for audit.

Enterprise Backend Configuration & Access Rights

Granular Security Groups Matrix

The module defines 3 distinct security access groups inside Odoo 17 User Settings. Each role strictly controls what the logged-in user can view, create, edit, or export:

Security Role Intended Staff Role Permissions & Capabilities
Activity User All Employees View own activity logs and session history.
Activity Manager Team Leads / Managers View team activity, dashboard, and reports.
Activity Administrator System Admins / Security Officers Complete administrative control over all logs, configuration, force logout, and user management.

System Configuration Parameters

  • Idle Threshold: Set idle timeout in minutes (default: 15).
  • Log Retention Days: Configure how long logs are kept (default: 365).
  • Excluded Models: List of models to exclude from tracking.
  • Report Recipients: Email addresses for daily/weekly reports.
  • Enable Suspicious Activity Alerts: Toggle security monitoring.
  • Enable Force Logout: Allow administrators to terminate sessions.

Key Data Models

  • activity.log: Main activity log with user, model, operation, and timestamp.
  • field.change: Field-level changes with old and new values.
  • user.session: Session details with login/logout, IP, user agent.
  • security.alert: Suspicious activity alerts with severity levels.
  • activity.config: System configuration for tracking options.

Integrations & External APIs

🔗 Odoo Native Integrations

  • Web (web): Session tracking, user agent parsing.
  • Mail (mail): Email report templates and sending.
  • HR (hr): Employee information for activity logs.
  • Base Automation: Automated cron jobs for cleanup and reporting.

📡 External Integrations

  • Log Export: Export logs to CSV/Excel for external analysis.

API Endpoints (REST)

  • GET /api/activity/logs: Retrieve activity logs with filters.
  • GET /api/activity/sessions: Get active and historical sessions.
  • GET /api/activity/dashboard: Real-time dashboard data.
  • POST /api/activity/force-logout/{user_id}: Force logout a user.
  • GET /api/activity/reports/daily: Generate daily report.
