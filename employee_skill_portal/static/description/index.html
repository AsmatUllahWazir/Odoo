Core Features

Employee Skill Inventory

Track technical, soft skills, certifications, tools with proficiency levels, years of experience & self/manager ratings.

Endorsement System

Request/approve endorsements with relationship types (manager, colleague, client). Anonymous option + endorsement score.

Certification Management

Store certification ID, expiry, issuing body, URL verification. Timeline view, expiry warnings, certificate gallery.

Public & Private Portal

Beautiful responsive portal: department grouping, search by skill/category/employee, top endorsed skills, recent certifications.

Skill Score & Matrix

Algorithmic skill score (self+manager+endorsements+exp). Gap analysis, assessment framework, skill matrix report.

Approval Workflow

Draft → Submitted → HR Review → Manager Approval → Approved. Verification badge & history.

Training Recommendations

Link skill gaps to training courses, online resources, internal workshops.

Advanced Search & Filters

Skill categories, tags, department groups, real-time search.

Fully Responsive Design

Glassmorphism cards, floating particles, intersection animations.

📊 Proficiency Details

Track years of experience, last used date, usage frequency, self rating, manager rating, and overall rating. Includes description, projects used, and key achievements.

⭐ Endorsements Management

View all endorsements received for a skill. Shows endorser name, date, rating (stars), relationship, status (approved/pending), and comments. Add new endorsements inline.

🏷️ Skill Tags

Configure tags for flexible skill categorization. Each tag has a name, color code, and active flag. Tags help in filtering and grouping skills across the organization.

Flexible

📁 Skill Categories

Hierarchical skill categories with parent-child relationships. Each category has a skill type, sequence, description, color, and icon. Organize skills logically.

Manage training courses linked to skills. Includes training name, type (online/classroom/workshop/certification), provider, duration, cost, course URL, and related skills.
