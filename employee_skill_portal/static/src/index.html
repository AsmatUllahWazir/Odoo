Core Features

Employee Skill Inventory

Track technical, soft skills, certifications, tools with proficiency levels, years of experience & self/manager ratings.

Endorsement System

Request/approve endorsements with relationship types (manager, colleague, client). Anonymous option + endorsement score.

Certification Management

Store certification ID, expiry, issuing body, URL verification. Timeline view, expiry warnings, certificate gallery.

Public & Private Portal

Beautiful responsive portal: department grouping, search by skill/category/employee, top endorsed skills, recent certifications.

Skill Score & Matrix

Algorithmic skill score (self+manager+endorsements+exp). Gap analysis, assessment framework, skill matrix report.

Approval Workflow

Draft → Submitted → HR Review → Manager Approval → Approved. Verification badge & history.

Training Recommendations

Link skill gaps to training courses, online resources, internal workshops. Skill.training model with provider, cost, duration.

Advanced Search & Filters

Skill categories, tags, department groups, skill type pill, real-time search in portal, category-based browsing.

Fully Responsive Design

Glassmorphism cards, floating particles, intersection animations, mobile-optimized grid.
