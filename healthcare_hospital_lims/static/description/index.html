Test Catalog & Pricing Engine

CONFIGURATION

Define and manage comprehensive test catalog with parameters, normal ranges, pricing, and panel compositions. Supports both individual tests and multi-test panels.

  • Test Parameters: Define test name, code, units, normal range (low/high), and critical values.
  • Pricing Structure: Set selling price, cost price, and insurance rates for each test.
  • Panels/Profiles: Group multiple tests into panels (e.g., CBC, Lipid Profile, Liver Function).
  • Category Management: Organize tests by department (Hematology, Biochemistry, Microbiology).

Test Order Management

CORE WORKFLOW

End-to-end test order lifecycle from creation to invoicing. Supports multiple test selection, priority levels, and automated sample management.

  • Order Creation: Quick patient search, multi-test selection, priority (Routine/Urgent/STAT).
  • State Machine: Draft → Confirmed → Sample Collected → In Progress → Results Entered → Verified → Invoiced.
  • Sample Management: Automatic barcode generation, sample type selection, and collection tracking.
  • Physician Integration: Link orders to referring physicians with digital signatures.

Sample Tracking & Barcode System

TRACKING

Complete sample lifecycle tracking with barcode generation, collection management, storage location, and chain of custody.

  • Barcode Generation: Unique barcodes for each sample with QR/CODE128 support.
  • Collection Management: Track collection date, time, collector, and sample type.
  • Storage Location: Manage sample storage with shelf and freezer locations.
  • Chain of Custody: Complete audit trail of sample handling from collection to disposal.

Result Entry & Validation

CORE FEATURE

Efficient result entry with automatic validation against normal ranges, abnormal flagging, and delta check alerts.

  • Grid Entry: Fast batch result entry with tab navigation.
  • Normal Range Validation: Auto-flag results as High (H) or Low (L) based on defined ranges.
  • Delta Check: Compare results with previous values for the same patient.
  • Technician Assignment: Track who entered and verified each result.
📊

Quality Control Management

QC ENGINE

Comprehensive quality control with Levey-Jennings charts, Westgard rules, QC material tracking, and lot management.

  • QC Charts: Visual Levey-Jennings charts with Westgard rule violation alerts.
  • QC Material: Track QC material lots, expiry dates, and target values.
  • Rule Violation Alerts: Automatic notifications for Westgard 1:2s, 1:3s, 2:2s, etc.
  • QC Reports: Generate comprehensive QC reports for accreditation.

Generate professional PDF lab reports with patient and test details, normal ranges, and physician signatures. Automatic invoice generation on order verification.

  • PDF Reports: Customizable QWeb report templates with logo and branding.
  • Normal Ranges Display: Show reference ranges alongside patient results.
  • Physician Signature: Digital signature field for verification.
  • Accounting Integration: Auto-create invoices on order verification with Odoo Accounting.

  • Turnaround Time (TAT): Average processing time from sample collection to result verification.

Detailed Operational Workflows & System Architecture

📋 Test Order Workflow

  • Order Creation: Physician creates order with patient and test selection.
  • Confirmation: Order is confirmed and sample barcode is generated.
  • Sample Collection: Sample collected, scanned, and linked to order.
  • Result Entry: Technician enters results with automatic validation.
  • Verification: Senior tech verifies results and flags abnormalities.
  • Reporting: PDF report generated and sent to physician.
  • Invoicing: Invoice automatically created in Odoo Accounting.

🔬 Quality Control Workflow

  • QC Material Setup: Define QC materials with target values and ranges.
  • QC Testing: Run QC samples alongside patient samples.
  • Chart Generation: Auto-generate Levey-Jennings charts for each QC material.
  • Rule Checking: Automatic Westgard rule evaluation and violation alerts.
  • Corrective Action: Log corrective actions for rule violations.
  • QC Reports: Generate comprehensive QC reports for accreditation.

📄 Reporting & Invoicing Workflow

  • Result Verification: Results are verified by authorized staff.
  • PDF Generation: Lab report generated with patient details and results.
  • Report Delivery: Report sent to physician via email or portal.
  • Invoice Creation: Invoice automatically created from order line items.
  • Payment Tracking: Integration with Odoo Accounting for payment tracking.

📈 Analytics & Monitoring

  • Real-time Dashboards: Test volume, TAT, revenue, and abnormal rate.
  • Department Analysis: Performance metrics by lab department.
  • Physician Reports: Test ordering patterns and revenue by physician.
  • Trend Analysis: Historical trend analysis for operational planning.

Enterprise Backend Configuration & Access Rights

Granular Security Groups Matrix

The module defines 3 distinct security access groups inside Odoo 17 User Settings. Each role strictly controls what the logged-in user can view, create, edit, or export:

Lab Technician Technicians / Phlebotomists Enter results, manage samples, run QC, view orders assigned to them.
Lab Supervisor Senior Technologists / Supervisors Verify results, approve QC, manage QC materials, configure tests.
Lab Manager Lab Directors / Administrators Complete administrative control over all LIMS data, configuration, reporting, and user management.
