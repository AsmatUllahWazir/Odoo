Module Overview

The Hospital LIMS (Laboratory Information Management System) is a comprehensive Odoo 17 module designed for hospital and clinical laboratories. It streamlines the entire lab workflow — from test ordering and sample collection to result entry, validation, reporting, and billing.

Patient-Centric

Manage patient demographics, medical history, and all lab interactions in one place.

Test Catalog

Extensive test catalog with pricing, normal ranges, and departmental categorization.

Analytics & QC

Built-in quality control, dashboards, and real-time analytics for lab performance.

Key Benefits

  • End-to-end lab workflow automation
  • Barcode & sample tracking
  • Automated result validation with normal ranges
  • Integrated invoicing & accounting
  • Real-time dashboards & KPIs
  • Multi-department & multi-location support

Features

Patient Management

  • Unique MRN (Medical Record Number) auto-generation.
  • Patient search by name, ID, phone, or email.
  • Comprehensive medical history tracking.

Test Catalog & Pricing

  • Test name, code, and description.

  • Department association (Hematology, Biochemistry, etc.).

Installation & Setup

1 Prerequisites

  • Odoo 17 (Community or Enterprise)
  • Python 3.10+ with required packages
  • PostgreSQL 13+
  • Dependencies: base, contacts, account, product, stock, sale, purchase, mail, hr

2 Installation Steps

  1. Place the healthcare_hospital_lims module in your Odoo addons directory.
  2. Update the apps list: Apps → Update Apps List
  3. Search for "Hospital LIMS" and click Install.
  4. Configure the lab settings: LIMS → Configuration → Settings
  5. Set up your test catalog, departments, and normal ranges.

3 Configuration

  • Set up Departments (e.g., Hematology, Biochemistry, Microbiology).
  • Define Test Catalog with name, code, price, and normal ranges.
  • Configure Sample Types (Blood, Urine, CSF, etc.).
  • Set Barcode Prefixes for sample tracking.
  • Configure Accounting integration (income accounts, tax rules).

Patient Registration

Patient is registered with demographics, contact details, and medical history.

  • Unique MRN (Medical Record Number) generated automatically.
  • Searchable by name, ID, or phone.
  • Complete history of all past test orders.

Test Order Creation

Doctor or clinician selects tests from catalog, sets priority, and submits.

  • Select patient and referring doctor.
  • Choose tests from catalog with pricing.
  • Set priority: Routine, Urgent, or Emergency.
  • Automatic state: Draft → Confirmed.

Sample Collection

Sample is collected, labeled with barcode, and sent to lab.

  • Barcode generated for each sample.
  • Collection date/time recorded.
  • Sample type validation against test requirements.
  • State transition: Confirmed → Sample Collected.

Result Entry

Lab technician enters results for each test, with automatic validation.

  • Results entered per test with normal range validation.
  • Abnormal results auto-flagged.
  • Quality control checks.
  • State transition: Sample Collected → In Progress.

Approval & Validation

Pathologist or lab manager reviews and validates results.

  • Review all results for accuracy.
  • Add clinical notes or comments.
  • Approve or request re-test.
  • State transition: In Progress → Completed → Approved.

Report Generation

Final PDF report is generated with all test results and interpretations.

  • Professional PDF report with letterhead.
  • Includes patient info, test results, normal ranges.
  • Abnormal results highlighted.
  • Auto-email to doctor and patient (optional).

Invoicing

Invoice is generated and sent to patient or insurance provider.

  • Automatic invoice generation on approval.
  • Itemized list of tests with prices.
  • Tax and discount support.
  • Integration with Odoo Accounting.

Troubleshooting

Sample Barcode Not Printing

Ensure the barcode printer is configured in Odoo settings. Check Settings → Technical → Barcode.

Results Not Auto-Flagging Abnormal

Verify that normal ranges are configured in the test catalog. Check LIMS → Configuration → Tests.

Invoices Not Generating

Check accounting configuration. Ensure income accounts are mapped to tests. Verify Settings → Accounting.

API & Extension Points

The module provides several extension points for customization:

  • Model Inheritance: class CustomTestOrder(models.Model):
      _inherit = 'lims.test.order'
      custom_field = fields.Char(string='Custom Field')
  • Automated Actions:

    Create automated actions for state transitions, email notifications, and QC triggers.

  • Report Templates:

    Override QWeb templates for custom report layouts.

  • API Endpoints:

    REST API endpoints for third-party integrations (LIS integration).
