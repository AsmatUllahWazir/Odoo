Installation & Setup

1 Prerequisites

  • Odoo 19 (Community or Enterprise)
  • Python 3.10+ with required packages
  • PostgreSQL 13+
  • Dependencies: base, contacts, account, product, stock, sale, purchase, mail, hr, pos

2 Installation Steps

  1. Place the salon_spa_management module in your Odoo addons directory.
  2. Update the apps list: Apps → Update Apps List
  3. Search for "Salon & Spa" and click Install.
  4. Configure the salon settings: Salon → Configuration → Settings
  5. Set up your branches, services, and staff profiles.

3 Configuration

  • Set up Branches (Downtown, Suburban, etc.).
  • Define Services with pricing, duration, and commission rules.
  • Configure Specialists with HR records and service assignments.
  • Set Working Hours and time slot intervals.
  • Configure POS integration and payment methods.

Appointment Booking

Customer books appointment via phone, walk-in, or online portal.

  • Select branch, service, and specialist.
  • Choose available time slot from timeline.
  • Customer details captured (name, phone, email).
  • Status: Draft → Confirmed.

Customer Check-In

Customer arrives at the salon and checks in at the front desk.

  • Search customer by name or phone number.
  • View appointment details and service history.
  • Mark as arrived / in-progress.
  • Status: Confirmed → In Progress.

Service Delivery

Specialist performs the service with real-time status updates.

  • Multi-step chemical waiting workflows.
  • Add-on services and product upsells.
  • Timer tracking for service duration.
  • Status: In Progress.

POS Checkout

Service completed and customer proceeds to checkout.

  • Transfer to POS with all service items.
  • Process payment (cash, card, wallet).
  • Capture staff tips.
  • Status: In Progress → Paid.

Complete & Done

Appointment fully completed and closed.

  • Invoice generated and sent to customer.
  • Commission and tips attributed to staff.
  • Customer history updated.
  • Status: Paid → Done.

Troubleshooting

Appointments Not Showing in Timeline

Check that the appointment status is not 'Draft' and the date/time is within the current view. Ensure the branch filter is correct.

POS Not Receiving Appointments

Verify that the appointment status is 'In Progress' or 'Confirmed' before transferring to POS. Check that the POS session is active.

Tips Not Appearing in Reports

Ensure tips are captured during POS checkout. Check that the staff member is correctly assigned to the appointment.

API & Extension Points

The module provides several extension points for customization:

  • Model Inheritance: class CustomAppointment(models.Model):
      _inherit = 'salon.appointment'
      custom_field = fields.Char(string='Custom Field')
  • Automated Actions:

    Create automated actions for state transitions, email notifications, and SMS triggers.

  • Report Templates:

    Override QWeb templates for custom report layouts.

  • API Endpoints:

    REST API endpoints for third-party integrations (online booking, payment gateways).
