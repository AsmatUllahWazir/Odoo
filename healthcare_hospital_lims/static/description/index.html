Installation & Setup

  1. Add module to addons path – place hospital_lims in Odoo addons directory.
  2. Install dependencies: pip install openpyxl pandas (for reporting).
  3. Activate developer mode → Apps → Update Apps List → Search "hospital_lims" → Install.
  4. Configure: Settings → LIMS → Set default lab, normal ranges, invoice journal.
  5. Create users with groups: Doctor, Lab Technician, Lab Manager.
./odoo-bin -c odoo.conf -u hospital_lims

Core Models & Data Structure

lims.patient

  • Fields: name, dob, gender, phone, email, address, medical_record_no
  • Relations: One-to-many with test orders

lims.test_order

  • Fields: patient_id, physician, order_date, priority, status, sample_type
  • States: Draft → Confirmed → Sample Collected → In Progress → Results Entered → Verified → Invoiced

lims.test_result

  • Fields: test_order_id, test_parameter, value, normal_range_low, normal_range_high, abnormal_flag, technician

lims.sample

  • Fields: barcode, collection_date, sample_type, container, storage_location, status

Detailed Feature Documentation

Patient Management

Complete patient registry with medical record number, contact details, and history of test orders. Integrated with Odoo's partner model.

Test Catalog & Pricing

Define test parameters, normal ranges, pricing, and panels. Supports combo tests (e.g., Complete Blood Count).

Test Order Creation

Form with patient search, test selection, priority (routine/urgent/stat), and sample type. Auto-generates order number.

Sample Tracking

Barcode generation for samples, scan-in, storage location tracking, and chain of custody.

Result Entry & Validation

Grid entry for multiple results, auto-validation against normal ranges, abnormal flagging (H/L), and delta checks.

Quality Control

Levey-Jennings charts, Westgard rules, QC material tracking, and lot management.

Report Generation

Customizable PDF reports with patient info, results, normal ranges, and physician signature block.

Accounting Integration

Automatic invoice creation on order confirmation, linked to Odoo's accounting module, with insurance support.

Analytics & Dashboards

Dashboard widgets: test volume by department, average TAT, revenue by test, and abnormal rate.

Notifications & Chatter

Real-time notifications on order status changes, result verification, and messaging between lab staff.

Search, Filters, Kanban

Advanced search with filters (status, date, physician), Kanban view for test orders, and list/tree views.

Best Practices & Tips

  • Always validate normal ranges for each test parameter.
  • Use barcode scanning to reduce sample mix-ups.
  • Set up automated QC alerts for Westgard violations.
  • Archive older orders periodically for performance.

Troubleshooting

Q: Samples not appearing in result entry? A: Ensure order status is "Sample Collected".
Q: PDF report missing logo? A: Check company branding settings in Odoo.
Q: Abnormal flag not showing? A: Verify normal ranges are defined for the test.

API / Extension Points

Extend the module via Odoo's standard API:

  • Inherit lims.test.order to add custom fields.
  • Override _compute_normal_range() for custom validation.
  • Use @api.onchange for dynamic form behavior.
  • Add new report templates via QWeb.
class TestOrder(models.Model):
    _inherit = 'lims.test.order'
    custom_field = fields.Char('Custom Field')
