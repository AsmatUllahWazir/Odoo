Frequently Asked Questions

Common questions about Smart Document AI

How does AI auto-categorization work?
The AI analyzes document content, file name, and metadata to match against predefined category keywords. It learns from your manual corrections and improves over time. Categories can be configured with custom keywords and allowed file extensions.
How does duplicate detection work?
Documents are compared using SHA-256 hash for exact duplicates and content-similarity algorithms for near-duplicates. When a duplicate is detected, you can merge documents, keep only the primary version, or archive duplicates.
What does full-text search include?
Full-text search indexes document names, file names, extracted text (OCR from PDFs and images), document summaries, and keywords. The search supports fuzzy matching for typo tolerance and relevance ranking.
What file formats are supported?
Supported formats include: PDF, DOC, DOCX, XLS, XLSX, PPT, PPTX, TXT, JPG, JPEG, PNG, TIFF, and ZIP. OCR extraction works for PDFs and image files.
How is document security handled?
Documents support four access levels: Private, Internal, Department, and Public. Granular user permissions and record rules control access. Full audit trail tracks views, downloads, and modifications.
Is version control supported?
Yes, documents support full version history. You can create new versions, track changes, and view previous versions. Each version is linked to its parent for complete traceability.
Does it work with Odoo Community Edition?
Yes! Smart Document AI works perfectly on both Odoo Community and Enterprise editions. All features are fully functional on Community Edition.
Can I customize the module?
Absolutely. The module is built with standard Odoo patterns and is fully customizable. You can modify views, add fields, extend models, and integrate with other modules.
