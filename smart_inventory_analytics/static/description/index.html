Powerful Features

Everything inventory managers need to reduce dead stock and improve turnover.

📦

Product Aging Buckets

Automatic classification: 0–30, 31–60, 61–90, 90+ days, and No Movement. Clear visibility of how long stock has been sitting.

⚠️

Dead Stock Detection

Configurable threshold (default 90 days). Composite score based on days, quantity and value so you prioritise the real problems.

🔄

Turnover & Velocity

30-day sold quantity and turnover rate per product. See which items move fast and which do not.

🛒

Smart Reorder Suggestions

Suggested quantity, priority (None → Critical) and clear reason — out of stock, below min, high velocity, etc.

📊

Modern Live Dashboard

Beautiful KPI cards, aging distribution, top dead stock and top reorder lists. Scrollable, responsive and eye-catching.

📄

Professional PDF Reports

Filter by bucket, dead stock only, high-priority reorders. Clean summary cards and detailed product table.

📷

Aging Analysis Snapshots

Run on-demand analyses. Store historical snapshots with full lines, totals and bucket distribution.

🌐

Manager Portal

Portal page at /my/inventory/aging with filters, sorting and pager for users with access rights.

⚙️

Configurable & Scheduled

Dead stock days in Inventory settings. Optional daily automatic analysis via cron.

How It Works

From install to insight in a few minutes.

1

Install & Assign Rights

Install the module and give users the Smart Inventory Analytics User or Manager group.

2

Configure Threshold (optional)

Set dead stock days under Inventory → Configuration → Settings. Default is 90 days.

3

Open the Dashboard

Go to Inventory → Inventory Analytics → Dashboard. See KPIs, aging buckets and top lists instantly.

4

Run Analyses & Reports

Create Aging Analyses for snapshots. Use Print Aging Report for professional PDFs with filters.
