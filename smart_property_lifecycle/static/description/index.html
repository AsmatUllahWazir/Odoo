Detailed Operational Workflows & System Architecture

🏠 Property Lifecycle Workflow

  • Property Onboarding: Create property with full details, images, and specifications.
  • Listing & Marketing: Publish to website with virtual tours and AR previews.
  • Viewing & Screening: Schedule viewings and launch tenant screening.
  • Leasing: Generate lease from template with e-signature and recurring invoices.
  • Occupancy: Manage occupancy with IoT monitoring and maintenance.
  • Renewal & Termination: Automated renewal reminders and termination workflows.

📄 Lease Management Workflow

  • Lease Creation: Create lease from property or viewing with full terms.
  • E-Signature: Send lease for electronic signature with tracking.
  • Activation: Activate lease with automatic invoice creation.
  • Renewal: Automated renewal detection with 60-day notice period.
  • Termination: End lease with deposit return logic.
  • Status Updates: Property and unit status updates on lease events.

🔧 Maintenance & IoT Workflow

  • IoT Alert: Smart devices send webhook alerts to the system.
  • Auto-Request Creation: Maintenance request auto-created from IoT alert.
  • Assignment: Request assigned to maintenance staff.
  • Scheduling: Schedule maintenance with date and duration.
  • Completion: Complete maintenance with cost tracking and resolution notes.

💰 Dynamic Pricing Workflow

  • Rule Creation: Define pricing rules with conditions and adjustments.
  • Cron Job: Daily cron job recalculates dynamic prices.
  • Market Factors: Apply seasonal, occupancy, and demand adjustments.
  • Custom Formulas: Use Python expressions for complex algorithms.
  • Real-time Updates: Prices update instantly on property views.

Enterprise Backend Configuration & Access Rights

Granular Security Groups Matrix

The module defines 5 distinct security access groups inside Odoo 17 User Settings. Each role strictly controls what the logged-in user can view, create, edit, or export:

Security Role Intended Staff Role Permissions & Capabilities
Property Manager Property Managers Full access to all properties, leases, viewings, maintenance, and reports.
Property Agent Real Estate Agents Manage assigned properties, create leases, schedule viewings.
Property Owner Property Owners Read-only access to owned properties and related data.
Tenant (Portal) Tenants Portal access to view leases, pay invoices, submit maintenance.
Property Analyst Analysts Read access for analytics and reporting.

Automated Workflows & Business Logic

  • Property Status Workflow: Draft → Listed → Under Offer → Leased/Sold → Maintenance → Archived.
  • Lease State Machine: Draft → Pending Signature → Signed → Active → Terminated/Expired.
  • Viewing Workflow: Scheduled → Confirmed → In Progress → Completed/Cancelled.
  • Maintenance Workflow: Reported → Assigned → Scheduled → In Progress → Completed.
  • Auto-Invoicing: Recurring invoices on lease activation with configurable frequency.
  • Dynamic Pricing: Daily cron job recalculates prices based on rules.
  • Renewal Detection: Automatic 60-day notice and renewal processing.
