Bill of Quantities (BOQ) Management with Excel Import

BUDGETING ENGINE

Create, manage, and approve detailed Bills of Quantities with full version control. Import BOQ data directly from Excel spreadsheets, and automatically generate job cost lines and material requisitions upon approval.

  • Excel Import/Export: Upload BOQ from Excel with automatic product creation and category mapping.
  • Version Control: Track BOQ revisions with version numbers and previous version references.
  • Auto-Generate Cost Lines: Approved BOQ automatically creates job cost lines and material requisitions.
  • Approval Workflow: Draft → Under Review → Approved → Auto-generates cost lines & requisitions.

Real-Time Job Costing & Budget Control

Enterprise Backend Configuration & Access Rights

Granular Security Groups Matrix

The module defines 2 distinct security access groups inside Odoo 17 User Settings. Each role strictly controls what the logged-in user can view, create, edit, or export:

Security Role Intended Staff Role Permissions & Capabilities
Construction User Project Engineers / Site Supervisors Read, create, and manage BOQs, requisitions, tasks, and checklists. View costs and progress.
Construction Manager Project Managers / Construction Managers Complete administrative control over all construction data, approvals, reporting, and configuration.

Automated Workflows & Business Logic

  • BOQ Approval Workflow: Draft → Under Review → Approved (or Rejected/Cancelled). Auto-creates cost lines and requisitions.
  • Requisition Workflow: Draft → Submitted → Approved → Partially Delivered → Delivered. Auto-creates POs and stock pickings.
  • Milestone Workflow: Planned → In Progress → Completed → Invoiced. Auto-calculates retainage and generates invoices.
  • Subcontractor Task Workflow: Pending → Assigned → In Progress → Under Review → Completed. Auto-generates vendor invoices.
  • Cost Variance Alerts: Real-time notification when costs exceed budget thresholds.
  • Overdue Task Monitoring: Daily notifications for tasks past deadline with escalation to managers.
