Real-Time Rate Shopping & Comparison

CORE WORKFLOW MAIN FEATURE

Powerful rate shopping engine that queries multiple carriers simultaneously and presents a side-by-side comparison of rates, delivery times, and service types. Users can easily compare costs and make informed shipping decisions.

📋 Rate Shopping Workflow
  1. Shipment Created: User creates a shipment with recipient details and package information
  2. Get Rates: User clicks "Get Rates" → System queries all active carriers
  3. Rate Comparison: Rates displayed side-by-side with costs, delivery days, and service types
  4. Selection: User selects the best rate → Shipment is updated with carrier details
  5. Label Generation: User generates shipping label with selected carrier
✨ Key Features
  • Real-time rate fetching from multiple carriers
  • Side-by-side comparison view
  • Fuel surcharge and residential surcharge breakdown
  • Estimated delivery date calculation
  • Recommended rate based on shipping rules
  • Rate history and audit trail
  • Rate caching for performance optimization

Intelligent Shipping Rules Engine

AI POWERED AUTOMATION

Powerful rule-based engine that automatically selects the best carrier and service based on configurable conditions. Reduce manual decision-making and optimize shipping costs with intelligent automation.

Weight Conditions Min/Max weight ranges for rule matching.
Destination Conditions Country, country group, state, ZIP code conditions.
Value Conditions Min/Max declared value for rule matching.
Action Rules Select carrier, override cost, delivery days, insurance, COD.
🧠 Example Rule:
# Domestic Ground for Small Packages { name: "Domestic Ground for Small Packages", condition_weight_min: 0.0, condition_weight_max: 5.0, condition_domestic: True, action_carrier_provider_id: UPS, action_service_type: GROUND, action_delivery_days: 3 }

🔐 Security Groups & Access Rights Matrix

🔐 Granular Security Groups

The module defines 3 distinct security access groups inside Odoo 17 User Settings. Each role strictly controls what the logged-in user can view, create, edit, or delete:

Security Role Intended Staff Permissions & Capabilities
Shipping User Shipping Staff View shipments, create shipments, get rates, generate labels, update tracking, create returns, view carrier providers and accounts.
Shipping Manager Shipping Managers All User permissions + manage carrier providers, manage carrier accounts, configure shipping rules, approve returns, configure settings, view all reports.
Shipping Administrator Administrators All permissions + full system configuration, user management, API logs, insurance policies, and all data access.

🔒 Model-Level Access Control

Access control is implemented at the model level using Odoo's security framework:

Read Access All groups have read access to relevant models based on their role.
Create Access Shipping User, Manager, and Admin can create shipments and returns.
Write Access Limited to authorized roles for sensitive operations.
Delete Access Restricted to Manager and Admin only for data integrity.
Additional Security Features:
  • Multi-company support with record rules
  • Audit trail with Chatter and activity tracking
  • Activity planning and notifications
  • Field-level security for sensitive data (API credentials)
  • Rate limiting for API calls
