The Problem: Odoo's Barcode Scanner Is Unreliable

PAIN POINT MOBILE

Warehouse operators across the Odoo community report the same recurring issues with Odoo's official mobile barcode scanner:

Crashes on iOSBarcode scanner crashes on modern iPhones (11 Pro and newer).
Stops WorkingScanner randomly stops working mid-session on iOS devices.
App-Only LimitationRequires a native mobile app — no browser fallback.
No Third-Party FixOdoo Online (SaaS) users can't install App Store modules.
✅

The Solution: Browser-Based Scanning

SOLUTION BROWSER

Stock Barcode Scanner Pro replaces the native-app dependency with a modern browser-based approach. If your device has a camera and a modern browser (Chrome, Safari, Firefox, Edge), it works.

📷

Scan-to-Increment Quantities

CORE FEATURE WORKFLOW

Point your camera at a product barcode. The module finds the matching move line in the picking and increments its quantity by 1. Every scan is debounced to prevent over-counting from rapid camera frames.

Auto-MatchMatches by product barcode, lot name, or serial number.
Auto-CreateCreates a move line if the product hasn't been detailed yet.
Debounced1.5s debounce prevents over-counting from rapid scans.
Live RefreshLine table updates immediately after every scan.
📱

Camera-Based Scanning

CORE FEATURE DEVICE

Powered by html5-qrcode. Uses the rear camera on mobile devices (facingMode: environment). Runs at 10 fps with a 250x150 scanning box. Works on phones, tablets, and laptops.

Supported Barcode Types:
  • 1D: EAN-13, EAN-8, UPC-A, UPC-E, Code 128, Code 39, Code 93, ITF, Codabar
  • 2D: QR Code, Data Matrix, PDF417, Aztec
⌨️

Manual Barcode Entry Fallback

FALLBACK RELIABILITY

When the camera isn't available — bad lighting, damaged barcode, or no camera — type the barcode into the manual input field and press Enter. Same server-side behavior as a camera scan.

🔍

Unknown Barcode & Tracked Product Warnings

VALIDATION SAFETY

If a barcode doesn't match any line in the picking, a yellow warning appears in the log. If a tracked product is scanned without a lot, a different warning appears. Nothing is modified until the scan is valid.

✅

Scan-to-Validate

CORE WORKFLOW FINISH

One button finishes the picking. The server calls button_validate() with skip_backorder=True and auto-handles the common SMS confirmation wizard, so the flow isn't interrupted.

🖥️

Full-Screen OWL Interface

UI OWL 2

A focused full-screen client action designed for one-handed mobile use. Large touch targets, minimal chrome, and a live scan log that shows the last 20 scans with color-coded success/warning/error states.

⏱️

Debounced Scanning

RELIABILITY PRECISION

The camera decodes the same barcode approximately 10 times per second. A 1.5-second debounce ensures a single scan results in a single quantity increment — critical for accurate counting.

🏷️

Lot / Serial Detection

TRACKING SAFETY

When a tracked product is scanned, the server returns a lot_required response and the UI shows a warning. This prevents silently creating untracked move lines for serialized products.

🔐

Security & Access Rights

SECURITY ACL

Access is controlled via Odoo's standard ACL. Only users in the Inventory / User group (stock.group_stock_user) can read and write pickings through the scanner. The controller enforces this on every request.

⚡

Built with OWL 2 for Odoo 17

MODERN OWL 2

Uses Odoo 17's native OWL 2 component system, service injection (orm, rpc, notification), and asset bundle. No legacy widget mixing, no patched core files, no monkey-patching.

🔄 Complete Scanning Workflows

From opening a picking to validating it — end to end

📋 Scan-to-Increment Workflow

  1. Open picking: Navigate to a receipt, delivery, or internal transfer.
  2. Click Scan Barcodes: Button in the picking header opens the scanner.
  3. Start Camera: Grant camera permission when prompted.
  4. Scan barcode: Point at a product barcode.
  5. Auto-match: Server finds the matching move line.
  6. Increment: Quantity increases by 1.
  7. Log entry: Green success message appears in the log.
  8. Line table refresh: Done quantity updates immediately.

✅ Validate Workflow

  1. Finish scanning: All required quantities scanned.
  2. Click Validate Picking: Single button at the bottom.
  3. Server validation: button_validate() runs with skip_backorder=True.
  4. SMS wizard: Auto-handled via action_skip().
  5. Backorder wizard: Auto-handled if it appears.
  6. Success: Green notification, picking is now Done.
  7. Line table refresh: Final state shown.

⚠️ Unknown Barcode Workflow

  1. Scan: Camera decodes a barcode not in the picking.
  2. Server lookup: No matching move line or move found.
  3. Response: { success: false, reason: 'unknown_barcode' }.
  4. Warning: Yellow message in log.
  5. No mutation: Picking is unchanged.
  6. Continue: User can scan the correct barcode next.

🏷️ Tracked Product Workflow

  1. Scan: Camera decodes a tracked product's barcode.
  2. Server lookup: Product found but tracking != 'none'.
  3. No lot provided: Response: { success: false, reason: 'lot_required' }.
  4. Warning: Yellow message in log.
  5. No mutation: No move line created.
  6. Fallback: User can scan the lot barcode to assign.

🚀 Installation & Setup

📥 Installation Steps

  1. 1 Copy stock_barcode_scanner_pro/ into your Odoo addons path.
  2. 2 Download html5-qrcode.min.js from GitHub releases.
  3. 3 Place it at static/src/lib/html5-qrcode.min.js.
  4. 4 Ensure __manifest__.py lists it first in web.assets_backend.
  5. 5 Restart Odoo with --dev=assets.
  6. 6 Go to Apps → Update Apps List → Install "Stock Barcode Scanner Pro".
  7. 7 Open any picking → click "Scan Barcodes".
  8. 8 Grant camera permission when prompted.
