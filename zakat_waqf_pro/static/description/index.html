Detailed Operational Workflows & System Architecture

⚙️ Zakat Calculation Workflow

  • Partner Selection: Select partner or company for Zakat calculation.
  • Asset Entry: Enter Cash, Inventory, Receivables, Gold/Silver, and Other Assets.
  • Madhhab Selection: Choose Hanafi, Shafi'i, Maliki, or Hanbali.
  • Nisab Check: System compares total wealth against 85g gold threshold.
  • Zakat Calculation: 2.5% of net wealth (after liabilities).
  • State Machine: Draft → Calculated → Invoiced → Certified → Paid.

📄 Certificate Generation Workflow

  • Certificate Request: Click "Generate Certificate" from calculation.
  • Verification: System verifies Zakat Due > 0.
  • Recipient Confirmation: Confirm recipient name and amount.
  • QR Code Generation: Unique QR code with verification data.
  • PDF Creation: Generate certificate with gold border and bilingual text.
  • Delivery: Print, email, or download the certificate.
  • Verification: QR code can be scanned for authenticity.

🏛️ Waqf Asset Management Workflow

  • Asset Creation: Create Waqf asset with name, type, and initial value.
  • Depreciation Setup: Set annual depreciation rate and salvage value.
  • Income Configuration: Set annual income and charity allocation %.
  • Beneficiary Assignment: Assign multiple beneficiaries.
  • Automatic Tracking: System tracks current value and depreciation.
  • Charity Distribution: Automated charity amount calculation.
  • Asset States: Active → Depreciated → Sold/Maintenance.

🏦 SADAD & Accounting Integration

  • Auto-Fetch: Pull cash, receivables, and inventory from Accounting.
  • Invoice Generation: One-click SADAD invoice creation.
  • Payment Tracking: Full integration with Odoo Accounting.

Enterprise Backend Configuration & Access Rights

Granular Security Groups Matrix

The module defines 3 distinct security access groups inside Odoo 17 User Settings. Each role strictly controls what the logged-in user can view, create, edit, or export:

Zakat User Finance Staff Create and view Zakat calculations, generate certificates, view Waqf assets.
Zakat Manager Finance Managers Approve calculations, manage Waqf assets, view all data.
Zakat Administrator Finance Directors Complete administrative control over all Zakat data, configuration, reporting, and user management.

System Configuration Parameters

  • Gold Price: Configurable gold price per gram for Nisab calculation (default: 250 SAR).
  • Zakat Income Account: Default income account for Zakat invoices.
  • Auto-Fetch: Enable/disable auto-fetch from Accounting module.
  • Default Madhhab: Set default Islamic school for new calculations.
  • Certificate Sequence: Configurable number sequence for certificates.

Key Data Models

  • zakat.calculation: Main Zakat calculation record with asset fields and state management.
  • zakat.certificate: Official certificate with QR code generation and PDF export.
  • waqf.asset: Waqf endowment asset with depreciation and income tracking.
  • res.config.settings: Global configuration for gold price, accounts, and defaults.

❓ Frequently Asked Questions

Is this module ZATCA compliant?

Yes, the SADAD invoice integrates with Odoo's standard accounting and works with ZATCA e-invoicing requirements when used with the l10n_gcc_invoice module.

Does it work with Odoo Community Edition?

Yes! ZakatPro works perfectly on both Odoo Community and Enterprise editions.

Can I customize the certificate design?

Absolutely. The certificate uses standard Odoo QWeb templates. You can modify colors, logos, and layout easily.

How is Zakat calculated?

Zakat = 2.5% of (Cash + Inventory + Receivables + Gold/Silver + Other Assets). Nisab threshold = 85g × current gold price (configurable in settings).

What if the total wealth is below Nisab?

Zakat Due will show 0.00 SAR, and certificate generation will be disabled until Nisab is met.
